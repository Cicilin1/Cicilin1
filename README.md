# Guilherme Cicilini

Atuo como Product Owner, com experiência em levantamento de requisitos, priorização de funcionalidades e evolução de produtos digitais, conectando as áreas de negócio e tecnologia.

Em paralelo, desenvolvo projetos próprios em C#, .NET e JavaScript, buscando aprimorar minhas habilidades em desenvolvimento de software, orientação a objetos e arquitetura de aplicações.

Meu objetivo é fortalecer a capacidade de transformar necessidades de negócio em soluções bem estruturadas, unindo visão de produto, raciocínio lógico e desenvolvimento técnico.

Atualmente, curso Bacharelado em Ciência de Dados pela Univesp.
